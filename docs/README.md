# NEXUS Impact Intelligence

NEXUS Impact Intelligence is a Samsung PRISM project for turning repository and project data into actionable impact intelligence.

## Project Status

Phase 1 is complete: the foundational project structure and handover documentation are initialized.

## Top-Level Components

- `backend` - Backend services and APIs
- `frontend` - User interface
- `agents` - Intelligence and automation agents
- `parser` - Source and document parsing
- `graph` - Knowledge graph components
- `rag` - Retrieval-augmented generation components
- `seed_repos` - Seed repositories and sample inputs
- `tests` - Project tests
- `docs` - Project documentation
- `presentation` - Project presentations and demos

See [PROJECT_STRUCTURE.md](PROJECT_STRUCTURE.md) for the complete structure and [HANDOVER.md](HANDOVER.md) for the current handover state.
